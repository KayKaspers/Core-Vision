# Core Vision Roadmap

## Foundation

### CV-WP-001 — Core Vision Project Bootstrap

Goal:

Establish the initial NDF-governed Core Vision project structure and capture the already confirmed strategic baseline.

### CV-WP-002 — Core Ecosystem Inventory & Classification

Goal:

Create the first authoritative inventory and classification of existing Core projects.

Initial candidates include:

- Core Vision
- Nova Development Framework
- Core Brain / Core-Brain-Pilot
- Core Design System
- Core-Dev
- CoreOps
- SpeakCore
- CastCore
- SC-OrgaBase
- future Core projects

### CV-WP-003 — Core Ecosystem Architecture & Boundaries

Goal:

Formalize:

- domain ownership
- authority boundaries
- capability boundaries
- standalone-first
- public-interface-first
- no implicit first-party trust
- graceful absence
- no bootstrap cycles
- authority preservation

### CV-WP-004 — Project Lifecycle, Intake & Cross-Project Governance

Goal:

Define how ideas become:

- research items
- capabilities
- features
- shared services
- products
- projects

and how cross-project governance is performed.

### CV-WP-005 — Ecosystem Integration Model

Goal:

Define logical and technical integration boundaries between:

- Core Vision
- NDF
- Core Brain
- Core-Dev
- CoreOps
- other Core products

without creating mandatory ecosystem lock-in.

### CV-WP-006 — Core Vision Software Architecture Discovery

Goal:

Only after the governance model is stable, evaluate the architecture of the future Core Vision software and Web UI.

No implementation technology is preselected.

## Delivery principle

Existing Core projects continue their approved development paths.

Core Vision Foundation work must not create unnecessary delivery freezes in other projects.
