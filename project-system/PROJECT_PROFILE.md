## Purpose

Core Vision is the strategic portfolio, architecture and governance layer of the Core ecosystem.

It provides a single authoritative place for ecosystem-level decisions without taking over the domain responsibilities of individual Core projects.

## Primary responsibilities

- ecosystem strategy
- portfolio management
- project classification
- project intake
- capability ownership
- architecture boundaries
- dependency governance
- technology assessment
- strategic roadmap
- strategic risk management
- cross-project decision records

## Explicit non-goals

Core Vision is not:

- an IDE,
- an Engineering Control Plane,
- an Operations Control Plane,
- the Development Governance Framework,
- the Knowledge & Evidence Plane,
- a replacement for product-specific governance,
- or a direct infrastructure management system.

## Current architecture status

No application stack has been selected.

No frontend, backend, database or runtime architecture is approved.

The Foundation phase intentionally defines governance, boundaries and information models before software architecture.

## Initial ecosystem relationships

### NDF

NDF defines how Core Vision itself and other projects are developed.

NDF does not own ecosystem strategy or portfolio authority.

### Core Brain

Core Brain may later provide evidence, provenance, retrieval and context.

Core Brain does not become ecosystem strategic authority.

### Core-Dev

Core-Dev provides Engineering Control Plane functionality.

Core Vision may consume aggregated development state later.

### CoreOps

CoreOps provides Operations Control Plane functionality.

Core Vision may consume aggregated operational information later.

### Core Design System

CDS provides shared design and brand foundations where applicable.

## Security and coupling principles

- standalone-first
- explicit trust
- least privilege
- public-interface-first
- graceful absence
- no bootstrap cycles
- authority preservation

## Current implementation policy

Documentation first.

Architecture first.

No Core Vision Web UI or application implementation before the Foundation governance and boundary model has been reviewed.
