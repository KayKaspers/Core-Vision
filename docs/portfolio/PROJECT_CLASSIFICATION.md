# Core Ecosystem Project Classification

**Status:** Foundation Draft

## Membership states

### CONFIRMED

The project is explicitly recognized as part of the Core ecosystem.

### OBSERVED CANDIDATE

A repository or concept exists, but its active ecosystem membership or role has not yet been approved.

### UNRESOLVED

The project is known, but identity or relationship information is incomplete.

### LEGACY REFERENCE

Historical or archived material that may remain useful as evidence or reference.

## Authority rule

Portfolio classification does not automatically grant authority.

Detailed capability and authority boundaries belong to CV-WP-003.

## Anti-assumption rules

Core Vision must not assume that:

- similar names mean identical projects,
- a repository automatically belongs to the active ecosystem,
- a repository replaces another project,
- an archived repository is active,
- absence of a public repository means absence of a project,
- integration transfers authority.

Unknown states remain unknown until resolved.
